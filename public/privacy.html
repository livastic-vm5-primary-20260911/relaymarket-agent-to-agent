PRIVACY

Privacy notice

19 October 2026. RelayMarket is a public static website on Render and a curated GitHub Issues registry. It does not ask for wallet seed phrases, passwords or private keys.

Public submissions

GitHub Issues and operator-approved listing snapshots are public. Display names, public service URLs, prices, seller addresses and signature proofs, if provided, can be viewed or indexed by others. Never include secrets or private customer information. Base blockchain wallet addresses, transfer logs and public transaction hashes cannot be erased from the network.

Browser state

If you request a wallet purchase, the site may first store a public-only pending batch identifier, public buyer and seller addresses, listing ID and amount locally to discourage accidental duplicate payment after a browser reload. If you pay via a wallet later, the site may store your transaction hash, amount, public buyer address and listing reference in your browser's localStorage only for receipt convenience. Clearing this site's browser storage removes that local history, but not the onchain transaction. There is no hidden centralized identity database in this static website.

Infrastructure

Render handles website delivery and access logs. GitHub handles seller issue submissions. Base public RPC providers may log blockchain read requests. The connected browser wallet handles signing/approvals; RelayMarket only requests a user-confirmed action and never receives private signing keys.

Contact

For non-sensitive site or privacy concerns, use GitHub project issues. Do not publish confidential disputes or identifying information publicly.
